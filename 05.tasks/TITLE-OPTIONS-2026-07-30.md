# Title and subtitle options, 2026-07-30

Recovered from the session transcript on 2026-08-03 so the list is not lost again. These
nine were drafted for the **removal synthesis** now archived at
`01.manuscript/archive/invasive-removal-carbon-debt.qmd`. The author picked **option 3**,
which the archived file still carries. The current manuscript,
`01.manuscript/invasion-rate-versus-stock.qmd`, is a different paper: a paired
meta-analysis of rate against stock under invasion, with removal no longer the subject.
Its title was set in commit `41660bc`, not chosen from this list.
